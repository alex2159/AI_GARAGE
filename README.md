# AI Гараж

MVP платформы для владельцев ретро-автомобилей в России: личный кабинет
(город проживания, гараж) и календарь событий в городе пользователя.
Интерфейс — строгая монохромная система (чёрный/белый, без градиентов
и теней), шрифты Inter и JetBrains Mono с кириллицей.

## Основная функциональность

- **Вход через Kimi (OAuth 2.0)** — сессия в httpOnly-куке `kimi_sid`.
- **Профиль** — имя и город проживания из фиксированного справочника
  (Москва, Санкт-Петербург, Казань, Нижний Новгород); e-mail read-only.
- **Гараж** — CRUD автомобилей пользователя: марка, модель, год,
  госномер РФ (валидация формата `А123БВ77`, регион 2–3 цифры),
  описание до 5000 символов. Все операции скоуплены владельцем
  (чужая запись неотличима от несуществующей).
- **Календарь событий** — события города из профиля (или явный `city`):
  фильтры по типу (встреча/выставка/ралли/фестиваль/другое) и диапазону
  дат, пагинация, сортировка по дате и времени. Наполнение — mock-источник
  (`EVENTS_SOURCE=mock`), идемпотентный сид по `externalId`,
  автозапуск при первом старте сервиса.
- **API-документация** — OpenAPI 3.0 на `/api/v1/openapi.json`,
  Swagger UI на `/swagger-ui`, healthcheck на `/api/v1/health`.
- **PWA** — manifest, service worker (app-shell кэш, API не кэшируется).

## Стек

React 19 + TypeScript + Vite + Tailwind + shadcn/ui · Hono + tRPC 11 ·
Drizzle ORM + MySQL (TiDB Serverless) · Zod · react-hook-form.

## Локальный запуск

```bash
npm install          # lock-файл в репозиторий не коммитится
cp .env.example .env # заполнить значения
npm run db:generate  # сгенерировать SQL по схеме (при изменении db/schema.ts)
npm run db:migrate   # применить миграции (не используйте db:push на TiDB!)
npx tsx db/seed.ts   # наполнить календарь mock-событиями (идемпотентно)
npm run dev          # http://localhost:3000
```

Проверки: `npm run check` (типы), `npm run build` (production в `dist/`),
`npm start` (production-сервер на порту 3000).

## CI

Готовый workflow `.github/workflows/ci.yml` (install → check → test → build)
не входит в коммиты: OAuth-токен, которым выполнялись коммиты, не имеет
scope `workflow`, и GitHub отклоняет push файлов workflow без него.
Добавьте файл вручную через веб-интерфейс GitHub или перевыпустите
токен со scope `workflow`.

## Структура

```
api/            # Hono-сервер: tRPC роутеры, REST (health, docs), OAuth
api/events/     # порт источника событий + mock-реализация + импортёр
contracts/      # общие zod-схемы и справочники (города, авто, события)
db/             # схема Drizzle, миграции, сид
src/            # фронтенд: страницы, компоненты, tRPC-клиент
docs/           # release notes
```
