# Release Notes — AI Гараж MVP

## Что реализовано

### Issue #2 — Скелет проекта, инфраструктура и аутентификация
- Проект React 19 + Vite + Tailwind + shadcn/ui, бэкенд Hono + tRPC 11 + Drizzle ORM.
- Вход через Kimi OAuth 2.0, JWT-сессия в httpOnly-куке `kimi_sid`.
- REST: healthcheck `/api/v1/health`, OpenAPI на `/api/v1/openapi.json`, Swagger UI на `/swagger-ui`.
- Таблица `users`, наблюдаемость (request-id, access-лог, клиентский лог-синк).

### Issue #6 — Профиль и справочник городов
- Фиксированный справочник: Москва, Санкт-Петербург, Казань, Нижний Новгород (`contracts/cities.ts`).
- API профиля: просмотр и обновление имени и города (валидация по справочнику, zod).
- Поле `city` в таблице `users`.

### Issue #1 — Гараж: CRUD автомобилей
- Таблица `cars` (FK → users с каскадным удалением, индекс по владельцу).
- Единая zod-схема для фронта и бэка: марка/модель ≤ 120 симв., год 1900–текущий,
  госномер РФ (кириллица, регион 2–3 цифры, нормализация регистра), описание ≤ 5000.
- tRPC-роутер `cars`: list / byId / create / update / remove; операции скоуплены
  владельцем (404 вместо 403 — факт существования чужой записи не раскрывается).

### Issue #4 — Хранилище событий и mock-источник
- Таблица `events` (externalId UNIQUE, тип enum, индекс `(city, eventDate)`).
- Порт источника `EventSourcePort` + mock-реализация: 28 событий
  (все 4 города × 7 дат от недели назад до месяца вперёд, все 5 типов).
- Идемпотентный импорт по `externalId`; автосид при первом старте,
  ручной сид `npx tsx db/seed.ts`; выбор источника — `EVENTS_SOURCE`.

### Issue #5 — API календаря событий
- `events.list`: фильтры `from`/`to`/`type`, пагинация, сортировка по дате и времени;
  город — из профиля или параметр `city`; 400, если город не задан нигде.
- `events.byId` (404 для несуществующего), публичный `events.types` с русскими названиями.
- OpenAPI-спецификация всех эндпоинтов календаря.

### Issue #3 — Фронтенд личного кабинета и календаря
- Монохромный интерфейс (чёрный/белый, без градиентов и теней): Inter + JetBrains Mono
  с кириллицей, фирменная плашка госномера с отделённым регионом.
- Каркас: чёрная боковая колонка на десктопе, нижняя навигация на мобильных
  (safe-area, таргеты ≥ 44 px).
- Страницы: Гараж (карточки авто, диалог добавления/редактирования с валидацией,
  подтверждение удаления, пустое состояние), События (фильтры, группировка по дням,
  карточка события, состояние «город не выбран»), Профиль (имя, e-mail read-only, город).
- PWA: manifest, SVG-иконки, service worker (app-shell; API не кэшируется).
- Лендинг и страница входа; редиректы по состоянию сессии.
